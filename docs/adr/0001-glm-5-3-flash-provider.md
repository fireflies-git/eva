# ADR 0001: Use GLM-5.3-Flash for text and multimodal analysis

Eva uses the official Z.AI standard Chat Completions endpoint (`https://api.z.ai/api/paas/v4`) with `glm-5.3-flashx` as the default model. Global reasoning effort is low; private reasoning is cleared for new user requests and retained only inside one immediate tool loop. Discord attachments are bounded and ephemeral, with images and files sent as data URLs and videos sent as validated provider-fetched URLs. The existing image-generation provider remains separate because GLM-5.3-Flash is a text-output model and GLM-Image is a different endpoint. Generic environment overrides remain available for deliberate rollback.
